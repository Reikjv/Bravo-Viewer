Inclui arquivos vazios e arquivos ainda não importados das pastas do autopiloto e dos serviços. Uma busca atualiza esta lista; não representa o armazenamento de todas as extensões.

Arquivos ativos representam uma cópia do momento. Atualizações substituem a versão consultada da mesma fonte; arquivos idênticos são reconhecidos para evitar importações repetidas. MCAP fica para uma próxima etapa de compatibilidade.

O que esta versão oferece e o que pode vir depois

O foco inicial é histórico de horas, operações, energia e ocorrências. Os demais tipos encontrados continuam acessíveis no inventário, mesmo quando ainda não têm análise ou gráfico dedicado.

Esta grade informa possibilidades, sem prever datas de implementação. Sensores, configuração e gravação determinam quais informações poderão ser utilizadas.

Equipamento e coleta

BLUEOS

A coleta continua com a tela fechada. Registra a telemetria disponível na API no intervalo escolhido e busca os logs existentes a cada 5 minutos. A API fornece uma amostra, enquanto os arquivos preservam as mensagens gravadas pelo roteador.

Armazenamento e continuidade

Os dados ficam no volume persistente da extensão. Atualizar o contêiner mantém o histórico. Nesta beta, a remoção automática de dados está desabilitada; acompanhe o espaço e exporte os registros periodicamente.

Os contadores podem ser reiniciados no autopiloto. Mudanças de placa ou resets exigem identificar a continuidade do equipamento nas observações. Esta versão mantém as fontes por host; não é um gerenciador de frota.
